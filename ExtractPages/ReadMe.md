# Extract Pages in InDesign

## Description
Script to extract pages from an InDesign document.

## Requirements
- InDesign 2025 or above.

## How to use
1. Put the 'ExtractPages_Startup.jsx' in the startup scripts folder. For example, on Mac, put it here: '/Applications/Adobe InDesign 2026/Scripts/startup scripts'.
2. Put the 'ExtractInDesignPages.jsxbin' in the Scripts panel folder. For example, on Mac, put it here:  '/Applications/Adobe InDesign 2026/Scripts/Scripts Panel'
3. Once you do the above steps, it is available in File > Extract Pages...
