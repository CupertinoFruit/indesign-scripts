Script to extract pages from an InDesign document.

Put the 'ExtractPages_Startup.jsx' in the startup scripts folder. For example, on Mac, put it here: '/Applications/Adobe InDesign 2026/Scripts/startup scripts'.

Put the 'ExtractInDesignPages.jsxbin' in the Scripts panel folder. For example, on Mac, put it here:  '/Applications/Adobe InDesign 2026/Scripts/Scripts Panel'
